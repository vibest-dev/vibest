# 与 herdr-gpui 的能力对照

基准：penso/herdr-gpui `e055680c`，herdr 0.9.5（client endpoint generation 1）。格子里写了用例编号（如 T7）的「已实现」有 e2e，编号见 [archive/e2e.md](archive/e2e.md)。写明「无 e2e」的项只有单元测试，不在那份覆盖里。
